# kurumu house

「暮らしに、ちょうどいい余白を。」をコンセプトにした、架空の地域工務店のモデルハウス見学予約LPです。Webデザインのポートフォリオとして自主制作しました。

[公開サイトを見る](https://coconattsu0723.github.io/kurumu-house/)

## 制作の目的

家づくりを考え始めた人が、写真から暮らしをイメージし、見学で確認できることや当日の流れを知ったうえで、予約へ進めるように設計しました。

## 制作で工夫した点

- リビング、キッチン、素材の写真を順に見せ、光の入り方や家事動線、素材の質感を伝えています。
- 見学の流れとFAQを予約フォームの前に置き、家づくりの計画が具体的でない段階でも見学できることを案内しています。
- スマートフォンからの閲覧を想定し、ページを読み進めながら予約に進めるよう、画面下部に見学予約ボタンを配置しています。

## 制作環境

- HTML / CSS / JavaScript
- Git / GitHub Pages
- スマートフォン・PC対応

予約フォームは操作確認用のデモです。入力内容の送信や実際の見学予約は行われません。
